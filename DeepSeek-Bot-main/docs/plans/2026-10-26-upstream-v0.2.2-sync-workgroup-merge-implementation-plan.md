### 2.3 已确认冲突面

1. **`memory.js`**
   - 0.2.2 把 `journal()` 重构为 `publish + applySteps + journalRow + recoverPending`。
   - G6R 把 `addEntry/replaceEntry/removeEntry` 拆成 `*Inner`，并在 journal 后调用 `reportWrite`。
   - 直接覆盖任一版本都会丢失另一版本能力。
2. **`groups.js`**
   - 0.2.2 删除旧 `ROOM_LATE_ROUNDS`，引入 `relayLimit`、`room.paused`、`continueRoom`。
   - 工作群副本仍基于 0.2.0 轮次逻辑；必须同步复制，不能只改原版。
3. **工作群 channel / bridge**
   - 当前工作群没有 `continue-room`；原版 0.2.2 有 `room-continue`。
   - 工作群要跨机继续，不能只在本机恢复。
4. **`client.js`**
   - 当前 feature `client.js` 与上游 0.2.2 不同；必须最后构建。
5. **文本换行**
   - 仓库文件多为 CRLF；临时 diff 工具会把整文件显示为变更。执行时所有文本替换必须保留文件原换行风格。
6. **上游新增文件无同名工作群冲突**
   - 可先原样复制；但 `src/client/index.js`、`sidebar.js`、`i18n.js`、`group-settings.js`、`cells.js` 等接线文件必须三方融合。
